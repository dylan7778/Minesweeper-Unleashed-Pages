# Minesweeper Unleashed — public pages

This repository contains only the game’s public home, privacy, and support pages. It does not contain the game source code.

## Publish on GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select **main** and **/ (root)**, then **Save**.
4. Wait for the Pages deployment to complete. The Pages screen displays the live site address.

Expected addresses once deployment completes:

- Home: https://dylan7778.github.io/Minesweeper-Unleashed-Pages/
- Privacy policy: https://dylan7778.github.io/Minesweeper-Unleashed-Pages/privacy.html
- Support: https://dylan7778.github.io/Minesweeper-Unleashed-Pages/support.html

Use the privacy and support addresses in their corresponding App Store Connect fields. Add the published privacy-policy link inside the game as well.
